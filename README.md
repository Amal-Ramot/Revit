# Revit Academy — המסלול של ניר מימון

אתר אינטראקטיבי ללימוד Revit: 13 שיעורים מודרכים, ומודל בית תלת־ממדי שנבנה שלב אחרי שלב (קירות, פתחים, רצפות, גג, מדרגות, ריהוט, חתכים, חומרים, מידות וטבלאות).

**Stack:** Next.js 15 (static export) · React 19 · React Three Fiber / three.js · טקסטורות פרוצדורליות (בלי קבצי תמונה).

## הרצה מקומית

```bash
npm install
npm run dev
```

## פרסום ב־GitHub Pages
